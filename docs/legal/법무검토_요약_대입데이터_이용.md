# 법무검토용 요약: 학교알리미·대학어디가·대학 홈페이지 입시데이터의 학원 이용 가능성

- 작성일: 2026-10-08 (각 웹페이지·법령은 이 날짜에 직접 열람·확인)
- 성격: 변호사 검토 전 1차 정리 자료. 법률 자문 아님.
- 이용 주체: 사설 학원(영리 사업자). 이용 목적: 재원생·학부모 대상 진학 상담 보조 서비스.

## 0. 결론 요약

| 데이터 출처 | 영리 이용 | 핵심 조건 | 위험도 |
|---|---|---|---|
| 학교알리미 자체 Open API | 가능 | 공공누리 제1유형(출처표시) | 낮음 |
| 학교알리미 데이터(공공데이터포털 경유) | 가능 | 공공누리 제3유형(출처표시+변경금지) | 낮음~중간(가공 시) |

## 1. 학교알리미 (schoolinfo.go.kr / 교육부·한국교육학술정보원)

### 1-1. 확인된 사실
- 공공데이터 이용정책 원문: "공공데이터법에 근거하여 학교알리미 홈페이지에서 제공하는 공공데이터는 누구나 이용가능하고, 영리 목적의 이용을 포함한 자유로운 활용이 보장됩니다. (공공데이터법 제1조, 제3조)"
  - 단서: "정보공개법 제9조의 비공개대상정보와 저작권법 및 그 밖의 다른 법령에서 보호하고 있는 제3자의 권리가 포함된 것으로 해당 법령에 따른 정당한 이용허락을 받지 아니한 정보는 제공 대상에서 제외됩니다. (공공데이터법 제17조)"
  - 같은 페이지 저작권정책: 저작권법 "공공저작물의 자유이용" 조항에 따라 교육부가 저작재산권 전부를 보유한 저작물은 별도 이용허락 없이 자유이용 가능
  - 출처: https://www.schoolinfo.go.kr/ng/pi/pnngpi_a01_l0.do
- API 제공목록(학교기본정보 API) 이용허락조건 원문: "출처표시 : 출처를 표시하면 영리 목적의 이용이나 변경 및 2차적저작물의 작성을 포함한 자유 이용을 할 수 있습니다." 공공누리 마크: "공공저작물 자유이용허락-출처표시"(제1유형). 요청제한횟수 "제한없음".
  - 출처: https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_l0.do
- API 이용안내 "OPEN API 사용 제한" 원문 3항목:
  1. "상업적 이용이 불가능한 API를 상업적으로 활용하는 경우"
  2. "트래픽 초과로 인한 시스템의 부하가 발생하는 경우"
  3. "공공의 목적이 아닌 기타 개인의 목적이나 불법적인 목적으로 API를 활용하는 경우"
  - 인증키 발급 시 "사용자 구분(개인,기업,기관) 정보와 사용목적을 등록" 필요
  - 출처: https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_m0.do
- 공공데이터포털 등재본 "한국교육학술정보원_학교알리미 공시정보"(목록 15098092): 이용허락범위 "공공저작물 : 출처표시, 변경금지 (제 3유형)", 비용 무료, 운영계정은 심의 승인 필요
  - 출처: https://www.data.go.kr/data/15098092/openapi.do

### 1-2. 근거 법령
- 공공데이터의 제공 및 이용 활성화에 관한 법률(공공데이터법, 시행 2026-08-28)
  - 제3조 제4항: "공공기관은 다른 법률에 특별한 규정이 있는 경우 또는 제28조제1항 각 호의 경우를 제외하고는 공공데이터의 영리적 이용인 경우에도 이를 금지 또는 제한하여서는 아니 된다."
  - 제3조 제5항: "이용자는 공공데이터를 이용하는 경우 … 법령이나 이용조건 등에 따른 의무를 준수하여야 하며, 신의에 따라 성실하게 이용하여야 한다."
  - 제17조 제1항: 제공대상 공공데이터의 범위 및 제외 사유
  - 출처(전문): https://www.nepla.ai/law/공공데이터의-제공-및-이용-활성화에-관한-법률 (국가법령정보센터 law.go.kr에서 재확인 권장)
- 저작권법 제24조의2(공공저작물의 자유이용): 국가·지자체가 업무상 작성하여 공표한 저작물 등은 허락 없이 이용 가능 (학교알리미 저작권정책이 원용하는 조항)
- 공공누리 제1유형: 출처표시 조건으로 영리 이용·변경·2차적저작물 작성 허용 / 제3유형: 출처표시 + 변경금지
  - 출처: https://ko.wikisource.org/wiki/틀:공공누리_제1유형

### 1-3. 검토 의견
- 학교기본정보 API(제1유형)는 출처표시 조건으로 학원 서비스에 사용 가능.
- 공공데이터포털 경유 데이터(제3유형)는 영리 이용 가능하나 "변경금지"가 붙으므로 가공 지표 산출·재구성에는 부적합. 가공이 필요하면 제1유형 경로 사용.
- 사용 제한 3항목 중 1항("상업적 이용이 불가능한 API")은 API별 이용허락조건 확인을 전제로 하므로, 추가 공시항목 사용 시 항목별 조건 확인 필요.
- 인증키 신청 시 사용자 구분 "기업", 사용목적을 실제 용도(학원 진학상담 서비스)로 정확히 기재할 것. 허위 기재는 제한 사유.
- 출처 표기 문안 예: "출처: 학교알리미(교육부·한국교육학술정보원), 공공누리 제1유형"

### 1-4. 미확인 사항
- 학교기본정보 외 다른 공시항목 API의 개별 이용허락조건
- 저장소(코드)에는 두 서비스 연동 코드가 없어, 실제 사용 엔드포인트·항목은 미확인

## 2. 대학어디가 (adiga.kr / 한국대학교육협의회, 이하 대교협)

### 2-1. 확인된 사실
- 저작권정책(원문):
  - ① "별도의 저작권 표시 또는 다른 출처를 명시한 경우를 제외하고는 원칙적으로 한국대학교육협의회에 저작권이 있습니다."
  - ② "협의회에서 제공하는 콘텐츠를 무단 변경, 복제·배포, 개작하는 경우에는 저작권법 제97조 5에 의한 저작재산권 침해죄에 해당함을 유념하시기 바랍니다."
  - ③ "협의회에서 제공하는 콘텐츠로 수익을 얻거나 이에 상응하는 혜택을 누리고자 하는 경우에는 저희 협의회와 사전에 별도의 협의를 하거나 허락을 득하여야 합니다."
  - ④ "협의 또는 허락을 얻어 자료의 내용을 게재하는 경우에도 출처가 한국대학교육협의회임을 반드시 명시하여야 합니다."
  - ⑤ 직접 링크 시 협의회 통지 + 저작권정책 링크 의무
  - ⑥ 협의회가 저작권 전부를 갖지 않은 자료는 단순 열람 외 이용 금지
  - 출처: https://www.adiga.kr/mbs/cop/copyrightPolicyView.do?menuId=PCMBSCOP1000
- 이용약관(원문):
  - 제15조 제2항: "회원은 대입정보포털의 사전 승낙 없이 서비스를 이용하여 어떠한 영리행위도 할 수 없습니다."
  - 제15조 제3항: "회원은 대입정보포털 서비스를 이용하여 얻은 정보를 대입정보포털의 사전승낙 없이 복사, 복제, 변경, 번역, 출판, 방송 기타의 방법으로 사용하거나 이를 타인에게 제공할 수 없습니다."
  - 제16조 제1항: 서비스·정보 등 지적재산권은 "정부에 소유권"
  - 제16조 제2항: 명시적 승인 없는 "수정, 대여, 대출, 판매, 배포, 제작, 양도, 재라이센스, 담보권 설정 행위, 상업적 이용 행위" 금지
  - 출처: https://www.adiga.kr/mbs/jdm/memberJoinView.do?menuId=PCMBSJDM1000
- 어디가 공식 Open API: 어디가·대교협·공공데이터포털 검색 결과 확인되지 않음(2026-10-08 기준). 존재 여부 미확인.
- 대교협이 공공데이터포털에 개방한 별도 데이터(대학알리미 계열)는 존재. 예: "한국대학교육협의회_대학알리미 대학 기본 정보" https://www.data.go.kr/data/15158963/openapi.do
- 대학들은 전년도 입시결과를 어디가에 공개 중이나 대학별 공개 범위가 상이(대교협 표준안 연구 공모 2026-08 보도)
  - 출처: https://hangyo.com/mobile/article.html?no=108726

### 2-2. 근거 법령
- 저작권법 제2조 제1호(저작물 정의), 제6조(편집저작물), 제91조~제98조(데이터베이스제작자의 보호), 제136조(권리의 침해죄)
  - 참고: 저작권정책 ②항이 인용한 "제97조 5"는 현행 저작권법 조문체계와 맞지 않음(2006년 전부개정 이전 구법 조문 번호로 보임). 현행 침해죄 조항은 제136조. 조문 번호 오류일 뿐 금지 취지는 유효.
- 공공데이터법 제27조 제1항: 제공대상 목록에 없는 공공데이터는 소관 공공기관의 장 또는 활용지원센터에 제공 신청 가능 (대교협에 정식 제공 신청하는 경로)
- 공공데이터법 제3조 제4항(영리 이용 제한 금지)은 "다른 법률에 특별한 규정" 또는 제28조 제1항 각 호 사유가 없는 한 적용. 대교협이 어디가 콘텐츠를 공공데이터 제공 목록에 올리지 않은 상태에서 저작권정책으로 영리 이용을 제한하는 것이 동 조항과 충돌하는지는 **법률 검토 필요 쟁점**.

### 2-3. 검토 의견
- 현 상태에서 무허락 영리 이용은 저작권정책 ③·이용약관 제15조 제2항 위반. 데이터 재게시는 제15조 제3항 위반.
- 입결 수치 자체는 사실 정보로 저작물성이 약하나, 대교협이 수집·정리한 집합물은 데이터베이스제작자 권리(저작권법 제93조) 및 부정경쟁방지법 (파)목 보호 대상이 될 수 있음.
- 권고: ① 대교협에 서면 협의·허락 요청(초안 별첨: `대교협_어디가_콘텐츠_영리이용_허락요청_공문_초안.md`), ② 허락 전까지 서비스에서 어디가 데이터 제외 또는 링크만 제공(링크 시 ⑤항 통지 의무 이행), ③ 공공데이터법 제27조 제공 신청 병행 검토, ④ 대학알리미 공공데이터로 대체 가능한 항목 식별.

### 2-4. 미확인 사항
- 어디가 공식 API 및 API 전용 약관의 존재
- 대학 입시결과를 어디가에 공개하도록 강제하는 법령 조문
- 대교협 저작권정책과 공공데이터법 제3조 제4항의 관계

## 3. 각 대학 홈페이지에서 입결·경쟁률 직접 수집

### 3-1. 관련 판례 (확인된 범위)
- 야놀자 v. 여기어때 **형사**: 대법원 2022년 5월 선고. 정보통신망법 위반(침입), 컴퓨터등장애업무방해, 저작권법 위반 모두 무죄 확정. 요지: 앱을 거치지 않고 서버에 접속하거나 크롤링했다는 사정만으로 접근권한 없는 침입이라 보기 어려움. 로그인 등 객관적 접근제한 조치 부재가 핵심.
  - 판결문 PDF: https://www.scourt.go.kr/sjudge/1652779958317_183238.pdf
  - 해설: https://v.daum.net/v/Fi3RbZBWW5
- 야놀자 v. 여기어때 **민사**: 1심 및 서울고법(2022-08) 부정경쟁행위 인정, 10억 원 배상. 2심 요지: 정상 접속으로 취득 가능한 공개 정보라도 자동화 대량 복제 후 영업 이용은 허용되지 않음. 대법원 확정 여부 미확인.
  - 출처: https://v.daum.net/v/20220826110606958
- 잡코리아 v. 사람인(2017년 대법원 확정): 채용공고 반복·체계적 크롤링을 데이터베이스제작자 권리 침해 및 부정경쟁행위로 인정. 손해배상 및 수집물 폐기 명령.
  - 출처: https://bizhankook.com/articles/27377.html , https://www.shinkim.com/kor/media/newsletter/1843
- 민다 v. 마이리얼트립(2025-07 보도): 크롤링 관련 1억5천만 원 배상 판결. 크롤링 민사책임 인정 흐름 지속.
  - 출처: https://byline.network/2025/07/28-500/
- 위 사건의 사건번호는 2차 자료에서 확인되지 않아 기재하지 않음. 대법원 종합법률정보에서 확인 요망.

### 3-2. 근거 법령
- 저작권법
  - 제2조 제1호: 저작물 = "인간의 사상 또는 감정을 표현한 창작물" → 입결 수치·경쟁률 등 사실 정보 자체는 비보호
  - 제6조: 편집저작물(소재의 선택·배열에 창작성 있는 경우 보호)
  - 제93조 제1항·제2항: 데이터베이스제작자는 "전부 또는 상당한 부분"의 복제 등을 금지할 권리. 개별 소재는 상당한 부분 아님. 단, 반복적·체계적 복제로 상당한 부분 복제와 같은 결과를 낳으면 침해
- 부정경쟁방지 및 영업비밀보호에 관한 법률
  - 제2조 제1호 (카)목(2021년 신설, 데이터 부정사용): 접근권한 제한·관리되는 데이터의 부정 취득·사용
  - 제2조 제1호 (파)목(성과 등 무단사용 보충적 일반조항): "타인의 상당한 투자나 노력으로 만들어진 성과 등을 공정한 상거래 관행이나 경쟁질서에 반하는 방법으로 자신의 영업을 위하여 무단으로 사용함으로써 타인의 경제적 이익을 침해하는 행위"
  - 제4조(금지청구), 제5조(손해배상). (파)목은 형사처벌 규정 없음(민사 구제만)
  - 출처: https://www.shinkim.com/kor/media/newsletter/1843 , https://www.lawtalk.co.kr/posts/171714
- 정보통신망 이용촉진 및 정보보호 등에 관한 법률
  - 제48조 제1항: 정당한 접근권한 없이 또는 허용된 접근권한을 넘어 정보통신망에 침입 금지 (위반 시 제71조 벌칙)
  - 대법원 2022 판결 기준: 공개 페이지 크롤링만으로는 침입 불성립. 로그인 우회·캡차 우회·차단 회피 시 성립 가능성
- 교육관련기관의 정보공개에 관한 특례법 및 시행령: 대학 공시항목(신입생 충원 현황 등)을 규정. 전형별 50%·70%컷 포함 여부는 미확인.
  - 시행령 전문: https://www.nepla.ai/law/교육관련기관의 정보공개에 관한 특례법 시행령

### 3-3. 검토 의견
- 형사 위험: 공개 페이지를 접근제한 우회 없이 수집하는 한 낮음(대법원 2022).
- 민사 위험: 자동화·대량·반복 수집 + 영업 이용 조합이면 DB권 침해(제93조)·(파)목 성과도용 주장 가능. 다만 선례는 모두 **경쟁사 간** 분쟁. 학원은 대학과 경쟁관계가 아니고, 입결 공개는 대학의 수험생 모집 목적 자발적 공개이므로 "타인의 경제적 이익 침해" 입증이 상대적으로 어려움 → 위험은 선례보다 낮다고 평가(작성자 의견, 동일 사안 판례 미발견).
- 대학 홈페이지 이용약관의 "무단 복제·배포 금지" 조항은 형사 근거는 아니나 (파)목 "공정한 상거래 관행 위반" 판단 자료로 사용될 수 있음.
- 국립대 자료 중 공공누리 표시가 있는 것은 해당 유형 조건에 따라 이용 가능. 입결 게시물에 표시 여부는 대학별 확인 필요.

### 3-4. 권고 (위험 낮은 순)
1. 공공데이터 경로 우선: 대학알리미(공공데이터포털)의 입학 관련 공시항목으로 확보 가능한 수치는 그 경로 사용
2. 수작업 수집 + 출처·확인일 표기: 자동화 대량 복제가 아니므로 제93조·(파)목 성립 가능성 최저
3. 자동 수집 시 최소 준수사항: robots.txt 준수 / 로그인·캡차·차단 우회 금지 / 요청 간격 제한 / 원문 PDF·화면 재게시 금지, 수치만 추출 / 명시적 크롤링 금지 약관 대학 제외 / 삭제 요청 시 즉시 삭제
4. 분쟁 촉발 행위 회피: 대학 로고·모집요강 원문 전재, 대학이 삭제한 과거 입결 계속 게시, 가공 서열화 자료의 홍보 사용

## 4. 변호사 확인 요청 쟁점 (우선순위)
1. 대교협 저작권정책(영리 이용 제한)과 공공데이터법 제3조 제4항의 충돌 여부, 제27조 제공 신청의 실효성
2. 학원의 대학 홈페이지 입결 수집이 부정경쟁방지법 (파)목 "경제적 이익 침해" 요건을 충족하는지
3. 전국 대학 입결의 연 1회 체계적 수집이 저작권법 제93조 제2항 단서(반복적·체계적 복제)에 해당하는지
4. 공공누리 제3유형 데이터의 "변경금지" 범위(정렬·필터링·학생 성적과의 비교 표시가 변경에 해당하는지)
5. 야놀자 민사 사건 대법원 확정 여부 및 최신 (파)목 증명책임 판례(2026-08 보도)의 영향
